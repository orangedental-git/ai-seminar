  KI bei orangedental                            Seminar, Präsentation
===============================================================================


  STARTEN
  ---------------------------------------------------------------------------

  index.html doppelklicken.

  Kein Server, kein Internet, keine Installation. Der Ordner läuft so wie er
  ist, auch vom USB-Stick. Er muss nur komplett bleiben.

  Getestet mit Chrome und Edge unter Windows.


  BLÄTTERN
  ---------------------------------------------------------------------------

  Pfeil rechts  /  Leertaste  /  Bild ab  /  Mausklick    vorwärts
  Pfeil links   /  Rücktaste /  Bild auf /  Rechtsklick  zurück

  Pos1                       zur ersten Folie
  Ende                       zur letzten Folie
  Zahl eintippen + Enter     direkt zu dieser Folie

  Manche Folien bauen sich in Schritten auf. Dort einfach weiterklicken,
  der nächste Schritt kommt auf derselben Folie.


  TASTEN
  ---------------------------------------------------------------------------

  F     Vollbild ein und aus       (F11 tut dasselbe)
  O     Übersicht aller Folien    Klick auf eine Folie springt hin
  P     Referentenansicht          zweites Fenster mit Notizen
  B     Weichzeichnung abschalten  wenn der Rechner ruckelt
  Esc   Übersicht schließen

  Auf einem Touchscreen: nach links und rechts wischen.


  VOR PUBLIKUM
  ---------------------------------------------------------------------------

  1.  Zuerst P drücken.  Es öffnet sich ein zweites Fenster mit den
      Notizen, der Laufzeit und einer Vorschau der nächsten Folie.

  2.  Dann das Hauptfenster auf den Beamer ziehen und F für Vollbild.

  Diese Reihenfolge einhalten. Andersherum kann der Vollbildmodus beim
  Fensterwechsel abspringen.

  Das Hauptfenster ist das, was das Publikum sieht.
  Das zweite Fenster bleibt auf dem Laptop.
  Geblättert werden kann aus beiden Fenstern.

  Die Notizen stehen nur im zweiten Fenster, dort aber immer. Auf dem Beamer
  erscheinen sie nie, auch nicht versehentlich.

  R    setzt die Laufzeit im Referentenfenster zurück


  WENN ETWAS KLEMMT
  ---------------------------------------------------------------------------

  Das zweite Fenster geht nicht auf
      Der Browser blockiert Popups. Für diese Seite erlauben und noch
      einmal P drücken. Ohne das zweite Fenster gibt es keine Notizen,
      im Hauptfenster erscheinen sie bewusst nicht, damit sie nie auf dem
      Beamer landen.

  Die Übergänge ruckeln
      B drücken. Schaltet alle Weichzeichnungen ab. Das Layout bleibt
      gleich, nur die Übergänge werden schlichter.

  Die Folie ist zu groß oder zu klein
      Passt sich automatisch an jeden Bildschirm an. Falls doch etwas
      seltsam aussieht: Fenster einmal in der Größe ändern.

  Nichts geht mehr
      Seite neu laden (F5). Das Deck startet wieder bei Folie 1.
      Mit Zahl + Enter kommt man sofort zurück an die Stelle.
